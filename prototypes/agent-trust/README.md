# Agent trust prototypes

These files measure current Argus behavior. They are not the change to merge.

`firmware-census.py` classifies firmware bumps. `hap-setup-contract.ts` calls the live delegate and the ffmpeg argument builder. `exact-optional-probe.mjs` compiles a bad optional assignment and a prepare-answer union. `verify-argus/` is a prototype verification skill for those local checks. It does not deploy and it does not contact the Mini.

Evidence from the runs on this branch is in `evidence/`.
